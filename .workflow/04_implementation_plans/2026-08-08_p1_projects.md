# Implementation Plan — P1: Projects and Native Layout

**Spec:** `.workflow/03_specs/2026-08-08_projects_spec.md`
**Architecture:** `.workflow/07_dev_notes/2026-08-08_projects_and_session_pairs.md`
**Classification:** Class B
**Status:** Proposed

## Goal

Add persistent configured Projects above existing herdr workspace/tab navigation. Preserve legacy workspace/tab behaviour when Projects are disabled. Fix remote routing for `create_tab`; do not add remote agent spawning until P2.

## Changes

### Relay configuration and grouping

- Add pure `relay/projects.py`: load/validate absolute `HERDR_PROJECTS_FILE`, normalize roots, resolve longest same-host cwd root.
- Invalid path/file/entry exits relay at startup on stderr. Unset variable returns zero Projects.
- Annotate full snapshot agents with `project_id` only on a match; omit key otherwise. Add optional field to `AGENT_EVENT_FIELDS`, never to required fields. Before broadcasting an incremental update, resolve Project again from its enriched cwd/host; emit `project_id: null` when unmatched so `dict.update` clears stale browser state.
- Cache latest full agents snapshot. On client connect, inside existing `try`, send `projects` (`id`, `label`, `host`, never cwd) then cached agents snapshot.

### Safe layout controls

- Recompute duplicate bare pane IDs on every poll. Existing pane-addressed commands (`respond`, `read_pane`, `send_keys`, `send_text`) fail closed when ID is ambiguous. Include `read_pane` — omitting it leaks another host's terminal content.
- Retain `create_tab`. Resolve the host by collecting every live agent whose `workspace_id` matches and taking the set of their hosts: empty ⇒ `unknown workspace_id`; more than one host ⇒ `ambiguous workspace_id`; otherwise call `run_herdr_result("tab", "create", "--workspace", workspace_id, "--focus", remote=resolved_remote)`.
- **Do not gate `create_tab` on the pane ambiguity set.** `workspace_id` is a separate ID space with its own collision; the pane set says nothing about it. Equally, do not test for "exactly one matching agent" — a workspace with three agents is normal, not ambiguous. The test is one distinct *host*.
- Keep existing `tab_created` reply. Unknown/ambiguous workspace returns error; no local fallback. Do not delete workspace/tab metadata or controls.

### Browser

- Preserve current workspace/tab rendering unchanged when `projects` is empty.
- When Projects exist, render stable Project cards in configured order. Selecting a Project filters agents by `project_id`, then reuses workspace and tab chips for that filtered set.
- Show zero-session Project as “No sessions”; P2 later adds Start session. Keep Other sessions visible and blocked-session hoist global.
- Retain `createTab`, `activeWorkspace`, `activeTab`, chip CSS, and `create_tab` WebSocket message. Ensure tab `+` appears only for a selected live workspace.
- Reset `activeWorkspace` and `activeTab` whenever the selected Project changes. A workspace ID carried across Projects filters the new Project to nothing.

### Tests

- Add `tests/test_projects.py` for config validation: unset, relative config path, malformed JSON, duplicate IDs/roots, relative cwd, unknown host.
- Test exact root, descendant root, longest root, sibling-prefix rejection, host mismatch, unmatched result.
- Extend relay command tests or add focused unit seams for ambiguous pane refusal and remote workspace resolution. Cover local and remote `create_tab` without invoking real herdr.
