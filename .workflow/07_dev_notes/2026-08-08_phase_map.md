# Phase Map — Projects, Sessions, and Pairs

**Date:** 2026-08-08
**Status:** P1–P3 complete; P4–P5 planned
**Architecture:** `2026-08-08_projects_and_session_pairs.md`

The product stays small: Projects are configured launch targets; native workspaces and tabs remain layout; sessions are independently runnable; Pairs are optional browser-only links.

| Phase | User outcome | Scope | Depends on |
|---|---|---|---|
| **P1 — Projects** | Browser shows configured Projects even with no live agent. Live sessions group beneath the correct Project. | Project config, cwd grouping, Project outer UI, retain native workspace/tab controls, fix remote `+ Tab`, fail closed on duplicate pane IDs. | — |
| **P2 — Start session** | From any Project, user starts an allowlisted agent as a standalone session in a new workspace, new tab, or split. | **P3 — Pairs and transfer** | User optionally pairs two live same-host sessions and transfers selected text by prefill, review, then send. | **P4 — UI shell and density** | Terminal composer stays visible; each view owns its own scroll; mobile terminal reclaims space; text size is adjustable. | Non-scrolling app shell, flex view exclusivity, mobile/desktop density, single shortcut path, persisted 12–22px text size. | P3 |
